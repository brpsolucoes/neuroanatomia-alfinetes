# Neuroanatomia · Alfinetes

App web de estudo para a aula prática de neuroanatomia: mapa interativo com os 43 alfinetes dos roteiros, cartões de estudo (Nome → Função → Imagem → Onde fica), prova e lista.

- Arquivo único (`index.html`), funciona offline e no celular.
- O progresso (dominado/revisar) fica salvo apenas no navegador de quem usa.
- Textos e imagens vêm dos slides de Neuroanatomia da disciplina; funções e localizações foram complementadas com conteúdo padrão de neuroanatomia. Confira sempre com o professor.
